# 🚀 How to Run the Project Locally

Follow these simple steps to set up and run the LangGraph Gemini Chatbot on your machine:

### 1. Clone or Open Project Folder
Open your terminal or VS Code inside the project directory.

### 2. Create & Activate Virtual Environment
python -m venv venv

# Activate virtual environment:
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate

### 3. Install Dependencies
pip install -r requirements.txt

### 4. Set Up Environment Variables (.env)
Create a `.env` file in the root folder and add your Google Gemini API Key:
GOOGLE_API_KEY=your_gemini_api_key_here

### 5. Run the Application
streamlit run streamlit_frontend_database.py
